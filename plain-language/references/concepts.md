# 概念关联解释

遇到用户分不清几个概念之间的关系时，直接说明每个东西是干嘛用的、它们之间怎么配合，不要甩比喻。

## 服务器 vs 云厂商 vs CDN

各自的作用：
- **服务器**：一台远程电脑，你的网站代码、数据库、图片文件都存在上面。用户访问你的网站时，就是向这台电脑请求数据
- **阿里云/腾讯云/AWS**：出租服务器的公司。你不用自己买实体电脑，去他们网站上租一台远程电脑，按月付费
- **CDN**：在全国很多地方放了很多台小服务器，提前存好你网站的图片、CSS、JS等静态文件。用户访问时，从这些离他最近的小服务器下载，比从主服务器下载快得多
- **七牛云/又拍云**：专门做CDN服务的公司。你把网站的静态资源（图片、视频）传给他们，他们帮你分发到全国各地的节点

关系：阿里云提供主服务器（放网站代码和数据库），七牛云提供CDN（加速静态文件下载）。用户访问网站时，网页代码从阿里云服务器加载，图片视频从离他最近的CDN节点加载。

## 前端 vs 后端 vs 数据库 vs 服务器

各自的作用：
- **前端**：用户能看到的界面，包括文字、图片、按钮、输入框。前端代码运行在用户自己的浏览器里
- **后端**：处理数据和逻辑的代码，运行在服务器上。比如用户点"登录"，后端负责检查密码对不对、生成登录凭证
- **数据库**：存数据的地方，比如用户信息、订单记录、文章内容。后端代码会从数据库读取数据或往数据库写入数据
- **服务器**：一台远程电脑，后端代码和数据库软件都运行在这台电脑上

配合流程：用户打开网页 → 前端代码从服务器下载到用户浏览器 → 用户填表单点提交 → 前端把数据发给后端 → 后端处理数据（比如检查密码） → 后端从数据库读取或写入数据 → 后端把结果返回给前端 → 前端展示结果

## 开发环境 vs 测试环境 vs 生产环境

各自的作用：
- **开发环境**：你自己电脑上的环境。你在这里写代码、改代码、调试，随便折腾，出错了不影响别人
- **测试环境**：一个和正式环境很像的环境，用来测试新功能有没有Bug。测试通过后才敢上线
- **生产环境**：正式给用户用的环境。这里的代码是最终版本，出错了会影响真实用户，所以要格外小心

关系：在开发环境写代码 → 提交到测试环境测试 → 测试通过了再部署到生产环境给用户用

## 域名 vs IP地址 vs DNS

各自的作用：
- **IP地址**：服务器的真实地址，是一串数字（如 192.168.1.1）。电脑之间通信时，实际用的是IP地址
- **域名**：IP地址的"别名"，比如 www.baidu.com。让人好记，不用背一串数字
- **DNS**：一个翻译服务。你输入域名时，DNS帮你查到对应的IP地址，然后你的电脑才能连上服务器

配合流程：你在浏览器输入 www.baidu.com → 浏览器问DNS这个域名对应的IP是多少 → DNS返回IP地址 → 浏览器用这个IP地址连上服务器 → 服务器把网页内容传回来
