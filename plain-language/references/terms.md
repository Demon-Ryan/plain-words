# 常见术语对照表

遇到表里没有的词，也按照同样的方式翻译：用法优先，格式为 `中文（English，就是XXX）`。

## 基础概念

| 技术术语 | 大白话解释 |
|---------|-----------|
| API（Application Programming Interface，应用程序接口） | 两个程序之间互相传话的规则。比如你的APP需要显示天气，它就通过API向天气服务要数据，天气服务把数据传回来 |
| SDK（Software Development Kit，软件开发工具包） | 别人写好的一整套工具，你直接拿过来用，不用自己从零写。比如微信支付SDK，你接进去就能让用户付款 |
| 框架 (Framework) | 别人搭好的程序骨架，规定了代码该怎么组织。你在骨架里填自己的内容就行，不用从头想结构 |
| 库/插件 (Library/Plugin) | 别人写好的功能代码，你直接调用就行。比如要生成二维码，不用自己写算法，找个库一行代码就能生成 |
| 组件 (Component) | 页面上一个独立的小模块，比如一个按钮、一张卡片、一个搜索框，可以重复使用 |
| 前端 (Frontend) | 用户能看到、能点到的部分，你打开一个网站，看到的文字、图片、按钮、动画都是前端 |
| 后端 (Backend) | 用户看不到的部分，在服务器上运行，负责处理数据、判断逻辑、存取数据库。比如你点"登录"，后端负责检查密码对不对 |
| 全栈 (Full Stack) | 前端和后端都会做，一个人能包揽整个网站从界面到数据的所有开发 |
| 全栈开发流程 | 先设计页面长什么样 → 写前端代码（把页面做出来） → 写后端代码（处理数据和逻辑） → 连数据库（存用户数据） → 测试（确保没问题） → 部署上线（放到服务器上让大家访问） |

## 硬件与基础设施

| 技术术语 | 大白话解释 |
|---------|-----------|
| 服务器 (Server) | 一台远程的电脑，24小时开机运行，你的网站代码、图片、数据都存在上面。用户访问你的网站时，其实就是向这台远程电脑要数据 |
| 云服务器/云主机 | 不是你的电脑，而是在网上租的一台远程电脑。好处是不用花钱买实体机器，按月付费，随时可换配置 |
| 阿里云/腾讯云/AWS | 出租云服务器的公司。你去他们网站上注册账号，选配置，就能租到一台远程电脑来用 |
| CDN (Content Delivery Network，内容分发网络) | 在全国各地放了很多台小服务器，提前存好你网站的图片、视频、网页文件。用户访问时，从离他最近的那台小服务器下载，打开速度更快 |
| 七牛云/又拍云 | 专门做CDN和图片/文件存储的公司。你把网站的图片、视频传给他们，他们帮你分发到全国各地 |
| 虚拟机 (Virtual Machine) | 在一台实体电脑上通过软件模拟出多台"虚拟电脑"，每台都能独立运行不同的系统和程序，互不干扰 |
| 容器 (Container) / Docker | 把程序和它运行需要的一切都打包进一个小包裹里。这个小包裹不管搬到哪台电脑上，打开就能直接运行，不用重新配置环境 |

## 网络相关

| 技术术语 | 大白话解释 |
|---------|-----------|
| 域名 (Domain) | 网站的地址名字，比如 www.baidu.com。起这个名字是为了让人好记，不用记一串数字 |
| IP地址 | 电脑在网络上的实际地址，是一串数字，比如 192.168.1.1。域名就是IP地址的"别名" |
| DNS（Domain Name System，域名系统） | 负责把域名翻译成IP地址的服务。你输入 www.baidu.com，DNS帮你找到对应的IP地址，然后才能连上服务器 |
| 网关 (Gateway) | 网络进出的"大门"，数据要进出你的网络，都必须经过它检查和转发 |
| 防火墙 (Firewall) | 网络的安全检查员，检查进出的数据包是不是安全的，可疑的会被拦住 |
| 代理 (Proxy) | 一个中间服务器，你通过它来访问别的网站。它可以隐藏你的真实IP，也可以加速访问 |
| HTTPS | 加密的网站传输协议。你输入密码、银行卡号时，HTTPS会把这些信息加密，防止别人偷看 |
| SSL证书 | 证明一个网站身份真实可信的电子证书。浏览器看到有效的SSL证书，才会显示那个小锁标志 |
| 端口 (Port) | 电脑上每个程序用来接收数据的"门牌号"。一台服务器上可以同时运行很多程序，端口就是用来区分数据该给哪个程序的 |
| 带宽 | 网络传输速度的上限。带宽越大，同一时间能传的数据越多，加载网页、看视频就越快 |
| 延迟/响应时间 | 你发出一个请求到收到回复之间的时间。比如点了一个按钮，等了2秒才有反应，延迟就是2秒 |

## 开发与工具

| 技术术语 | 大白话解释 |
|---------|-----------|
| 终端/Terminal/命令行/命令提示符 | 电脑上可以输入文字命令的窗口。Windows上叫"命令提示符"或"PowerShell"，Mac上叫"终端"。打开方法：Windows按Win+R输入cmd回车；Mac在"启动台"搜"终端" |
| IDE / 编辑器 | 专门用来写代码的软件，有代码高亮、自动补全、报错提示等功能。常见的有 VS Code（免费）、WebStorm（收费） |
| VS Code | 微软出的免费代码编辑器，功能强大，插件多，是目前最流行的代码编辑工具 |
| 环境 (Environment) | 程序运行需要的软件和配置的总称。比如运行一个Node.js项目，需要先装好Node.js这个软件，这就是环境的一部分 |
| 开发环境 | 你自己电脑上用来写代码、测试代码的环境。这里可以随便改、随便试，出错了也没关系 |
| 生产环境 | 正式上线给用户用的环境。这里的代码是最终版本，不能乱改，出错了会影响真实用户 |
| 沙盒 (Sandbox) | 一个隔离的运行空间，里面的操作不会影响到外面的系统。比如浏览器里的沙盒，网页里的病毒跑不出来 |
| 工作目录 / 项目目录 | 你当前正在操作的那个文件夹。你在终端里输入命令时，命令是在这个文件夹里执行的 |
| 根目录 | 一个项目最顶层的文件夹，里面可能有子文件夹和文件。从根目录开始往下找，就能找到项目里的所有东西 |
| 相对路径 | 从当前文件夹出发，找到目标文件的路径写法。比如 `./images/logo.png` 表示当前文件夹下的images文件夹里的logo.png |
| 绝对路径 | 从电脑最顶层（比如C盘或根目录）出发，完整写出到达目标文件的路径。比如 `C:/Users/张三/project/images/logo.png` |
| 包管理器 (npm/yarn/pnpm) | 自动帮你下载和管理代码依赖的工具。你需要什么功能，告诉它名字，它自动从网上下载安装 |
| Git | 记录代码每次修改的工具。你改了一行代码，Git就记下来，以后随时可以回退到这行代码之前的状态 |
| GitHub / GitLab / Gitee | 存放代码的网站，可以把代码上传上去备份，也可以多人协作开发。GitHub是国外的，Gitee是国内的 |
| CI/CD（Continuous Integration / Continuous Deployment，持续集成/持续部署） | 自动化的代码处理流程。你提交代码后，它自动帮你测试、打包、部署上线，不用手动一步步操作 |
| Docker | 把程序和它运行需要的一切都打包成一个"镜像"。这个镜像在任何安装了Docker的电脑上都能直接运行，不用重新配环境 |
| 日志 (Log) | 程序运行过程中自动记录的文本信息，写了什么操作、出了什么错。程序出问题的时候，看日志就知道发生了什么 |
| 路由 (Route) | 决定用户访问不同网址时，应该显示哪个页面的规则。比如访问 `/home` 显示首页，访问 `/about` 显示关于页 |
| 中间件 (Middleware) | 在请求和响应之间插入的处理环节。比如用户请求一个页面，中间件先检查他有没有登录，没登录就拦住不让看 |
| Token | 一串用来证明你身份的字符。你登录成功后，服务器给你一个Token，之后你每次请求都带上它，服务器就知道你是谁 |
| 密钥/Secret Key | 一串秘密的字符，用来加密数据或者证明身份。绝对不能泄露给别人，泄露了别人就能冒充你 |
| Cookie | 网站存在你浏览器里的小数据，用来记住你的登录状态、偏好设置等。下次访问同一个网站时，浏览器会自动带上这些数据 |
| Session | 服务器端保存的用户状态信息。你登录后，服务器在内存里记着你已经登录了，一段时间不操作就自动清除 |

## 数据与存储

| 技术术语 | 大白话解释 |
|---------|-----------|
| 数据库 (Database) | 专门用来存数据的软件系统。可以存用户信息、订单记录、文章内容等，支持快速查找、添加、修改、删除 |
| SQL（Structured Query Language，结构化查询语言） | 和数据库对话的语言。用SQL可以问数据库要数据（查）、存新数据（增）、改已有数据（改）、删掉数据（删） |
| JSON | 一种数据格式，用花括号和大括号把数据组织起来，人容易看懂，程序也容易解析。广泛用于网页和服务器之间传数据 |
| 接口 (Interface/Endpoint) | 程序对外提供的一个"访问入口"。别的程序或网页通过调用这个接口，可以获取数据或触发某个功能 |
| 部署 (Deploy) | 把写好的代码上传到服务器，配置好运行环境，让用户可以通过网址访问到 |
| 构建 (Build) | 把开发时的源代码转换成最终可以运行的文件。比如把多个文件合并、压缩、转换格式，生成浏览器能直接运行的代码 |
| 编译 (Compile) | 把人写的高级编程语言（如C++、Java）翻译成电脑能直接执行的机器语言 |
| 依赖 (Dependency) | 你的项目需要用到的别人写好的代码包。比如你要做一个日期选择功能，不用自己从零写，找一个日期库直接用 |
| node_modules | 存放依赖包的文件夹，里面全是别人写好的代码。你运行 `npm install` 后，下载的依赖包就放在这里 |
| 环境变量 (Environment Variable) | 存在操作系统里的配置值，程序启动时可以读取这些值来决定怎么运行。比如设置一个变量告诉程序"现在是在开发模式还是生产模式" |
| 缓存 (Cache) | 把常用的数据临时存一份，下次需要时直接从缓存里拿，不用重新计算或重新下载，速度更快 |
| 回调 (Callback) | 你写的一个函数，传给另一个函数，等那个函数做完事情后再回过头来执行你写的这个函数 |
| 异步 (Async) | 程序发起一个耗时的操作（比如下载文件）后，不用干等着，继续执行后面的代码，等下载完了再回来处理结果 |
| 同步 (Sync) | 程序必须等一个操作做完，才能继续执行后面的代码。就像排队，一个一个来 |
| 开源 (Open Source) | 代码公开在网上，任何人都可以免费看、免费用、免费改。大多数开源项目放在GitHub上 |
| 云函数/Serverless | 你不用租服务器、不用配环境，直接把一段代码上传到云平台。有人访问时，云平台自动运行你的代码，按调用次数收费 |
| Bug | 程序里的错误或缺陷，导致程序没有按预期工作 |
| Feature | 程序的一个功能或特性。比如"支持微信支付"就是一个Feature |
| 回滚 (Rollback) | 出问题后把代码退回到之前的版本，就像撤销操作 |
| 灰度发布 | 新版本不一次性推给所有用户，先给一小部分用户试用。没问题了再慢慢扩大范围，有问题及时撤回 |
| A/B测试 | 同时上线两个不同版本，一半用户看到A版，一半用户看到B版，看哪个版本效果更好 |
