# 弹窗与权限术语大白话

当用户遇到弹窗提示、权限请求、安全警告时，用大白话解释每个选项的含义。

## 常见弹窗选项

| 选项/按钮 | 大白话解释 | 什么时候点 |
|-----------|-----------|------------|
| 确认 / Confirm | "我同意/我知道了"，表示你认可上面说的内容，允许它继续 | 只有你真的看懂了提示内容，并且同意时才点 |
| 允许 / Allow / 同意 | "你可以做这件事"，授权程序执行某个操作 | 信任这个程序时才点。如果不信任，先查一下它为什么要这个权限 |
| 阻止 / Block / 拒绝 | "你不许做这件事"，拒绝程序执行某个操作 | 你不确定要不要给它权限，或者它要的权限你觉得不合理 |
| 取消 / Cancel | "我不操作了，回到原来的状态"，啥也不做，回到之前的样子 | 不确定的时候先点这个，想清楚再操作 |
| 忽略 / Ignore / 跳过 | "我假装没看到，继续往下走"，不理会这个提示 | 这个提示不重要，或者你知道它不会造成问题时 |
| 始终允许 / Always Allow | "以后永远同意，不再问我" | 只有完全信任的程序才点，否则它会一直拥有这个权限 |
| 仅此次允许 / Allow Once | "就同意这一次，下次还要再问我" | 不确定时选这个，比较安全 |
| 加白名单 / 加入信任列表 / Add to Whitelist | "以后这个程序/这个网站是好人，不用再拦它了" | 你确定它是安全的、正常的程序/网站 |
| 移出白名单 / Remove from Whitelist | "以后这个程序/这个网站按普通规矩检查" | 发现某个白名单里的程序行为异常时 |

## 常见权限类型解释

| 权限名称 | 大白话解释 | 风险说明 |
|----------|-----------|----------|
| 访问文件/文件夹 | 程序要看/改你电脑上的文件 | 可能看到你的私人文件，恶意程序会删掉或偷走你的文件 |
| 访问网络/联网 | 程序要连接互联网 | 正常程序都需要，但恶意程序可能上传你的数据 |
| 访问摄像头 | 程序要看你的摄像头画面 | 可能被偷拍，非视频通话类程序要这个权限要警惕 |
| 访问麦克风 | 程序要听你的声音 | 可能被窃听，非语音类程序要这个权限要警惕 |
| 读取剪贴板 | 程序要看你复制的内容 | 可能看到你复制的密码、银行卡号等敏感信息 |
| 安装其他程序 | 程序要帮你装别的东西 | 可能被捆绑安装垃圾软件 |
| 修改系统设置 | 程序要改你电脑的配置 | 可能改坏你的电脑设置 |
| 获取管理员权限 / Root权限 | 程序要以"最高权限"运行，想干什么都能干 | **非常危险**，除非完全信任，否则不要给 |

## 解释弹窗的通用模板

看到弹窗时，按这个结构解释：
1. **这个弹窗是干嘛的** — 用一句话概括
2. **它要你的什么权限/要你确认什么** — 具体说明
3. **每个按钮的区别** — 用"如果你点了A会怎样，点了B会怎样"的格式
4. **建议你怎么选** — 给出推荐选项
